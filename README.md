# Snake Game

A classic Snake game implemented in Python using [pygame](https://www.pygame.org/).

## Requirements

- Python 3.8+
- pygame 2.x

## Installation

```bash
pip install -r requirements.txt
```

## Running the Game

```bash
python snake.py
```

## Controls

| Key | Action |
|-----|--------|
| Arrow keys / WASD | Move the snake |
| P | Pause / Resume |
| R | Restart (after game over) |
| Escape | Quit |

## Rules

- Guide the snake to eat the red food.
- Each piece of food adds 1 to your score and grows the snake by one segment.
- The game ends if the snake hits a wall or runs into itself.
